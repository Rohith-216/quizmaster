# QuizMaster - Online Quiz & Assessment Platform

## Objective

QuizMaster is a web-based Online Quiz & Assessment Platform developed using React.js. The application enables users to register, take timed quizzes, view results instantly, track scores, and compete on a leaderboard. Administrators can monitor users and quiz attempts through an admin dashboard.

---

## Features

### User Features
- User Registration & Login
- Secure Authentication
- Timed MCQ-Based Quizzes
- Instant Score Calculation
- Result Generation
- Percentage Calculation
- Leaderboard Ranking
- Responsive User Interface

### Admin Features
- Admin Login
- Dashboard Overview
- User Monitoring
- Quiz Attempt Tracking

### Additional Features
- React Router Navigation
- Context API State Management
- LocalStorage Data Persistence
- Auto-created Admin Account
- Mobile Responsive Design

---

## Tech Stack
